# 0.6.0之后：覆盖率与结构重绘计划（待审阅）

0.6.0的游戏外部挂载已由用户基本实测通过。以下只作为计划，不在本次发布中改变计算或绘图行为。继续采用develop开发、main发布，每阶段交付测试JAR及数据包。

## 1. 建立实际覆盖基线

以目标GTNH实例的 `/gtmoldraw audit` 导出为准，扩充导出流体身份、非GT材料适配来源、显示失败及未绑定原因。按稳定身份去重，区分“发现”“公式可解析”“组成可算”“质量模式可用”“结构可显示”。现有1,039条声明和368份结构不作为覆盖率分母。

输出CSV及可筛选HTML核对页；需要批量审核时再增加Excel工作簿及审核导入。首先定位有结构但身份未匹配、名称冲突、缺元素映射和缺组成等高收益问题。需要用户提供当前实例audit与日志，避免凭资源文件猜测整包材料。

## 2. 扩充组成与公式覆盖

优先修复身份/别名/流体绑定，补齐GT之外的材料适配器，再补组成及缺失公式。纯元素保留单质展示；合金、矿物、混合物优先饼图；有明确定义的离散分子优先结构图。数量与质量结果分别验收。

注册表中无可靠组成的材料标记为待审核，不编造质量或比例。幻想材料、配方中间体、非化学混合物、可变计量固体和聚合物分别记录来源与适用表达；不为它们强行套用单一真实分子。目标是尽可能覆盖所有可识别材料，并使剩余缺口可解释、可追踪，而非承诺100%材料都能生成正确结构。

## 3. 接入MOL二维结构与候选核验

先落实约定的MOL V2000二维导入，转换为现有JSONC模块/原子/键声明。保留原子、电荷、同位素、明确的氢和立体信息；无法表达的内容报错，不静默丢弃。导入不自动绑定GT材料。

随后提供离线候选查询工具：使用材料名称、别名及已有标识查找候选，结合分子式、电荷、同位素、盐/水合物状态及InChIKey等核验。只自动接受唯一且一致的结果；同分异构体、互变异构、混合物和别名歧义进入审核。保存数据库ID、来源、获取日期和人工决定，支持重现与增量更新。游戏只加载审核后的静态数据，不在启动或悬停时联网查询。

参考接口：[PubChem PUG REST](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest)、[MolView功能说明](https://molview.com/features/)。实施前另行确认数据源的适用条件、使用限制与导出格式。

## 4. 统一结构画法

先选取水、无机离子、苯/苯酚、稠环、立体键、长链和聚合物等代表样本，制作重绘前后图册供用户确认，再批量迁移。风格参考MolView与PubChem二维图示，使用可编辑的结构数据自行绘制，不直接把数据库截图用作游戏资产。

统一骨架式碳/氢省略规则、键长/键角、线宽、双键内侧偏移、三键间距、楔形/虚线、电荷/同位素/显式氢及标签避让。苯环继续采用凯库勒式；统一处理稠环共享边、交替键和内侧双键，避免旧式圆环与新风格混用。聚合物保留重复单元括号、连接端口及n标记；复杂固体不画成误导的离散分子。

数据库二维坐标优先在离线工具中清理；游戏只布局显示既有坐标。保留旧数据备份与逐材料差异记录，可按包撤销。提供不同缩放、字体、语言与配色的图册，并回归NEI、ChromaticTooltips、Shift、F3+T及热重载。

## 交付顺序与验收

| 阶段 | 交付物 | 核心验收 |
|---|---|---|
| A 覆盖审核 | 扩充audit、HTML/CSV基线与缺口清单 | 所有发现身份有明确状态，分母可复核 |
| B 覆盖扩充 | 身份/组成修复包及必要适配器 | 覆盖增量有实机证据，质量/数量计算正确 |
| C 导入与样板重绘 | MOL导入工具、代表结构对照图册 | 无信息静默丢失，样板风格经用户确认 |
| D 批量补图与重绘 | 经核验的候选与新版官方包 | 异构体不误绑，逐项差异可审核与撤销 |

各阶段先自动检查，再由用户实机验收；数据-only修复与绘图算法改动分批交付。已有Release与标签保持不变。

## 0.7-D集中交付与自动验证

通过原生ChromaticTooltips enricher替代该环境中的瞬时NEI行令牌，统一IFluidContainerItem流体识别；早期启动检查阻止改名或历史ID的重复安装。独立Java子进程验证实际Chromatic接口、布局回调与安装检测；隔离真实客户端完成40个原生提示框场景和20次图形绘制，无GL错误。实际储罐／NEI鼠标悬停和像素美观仍需交互验收，详见TESTING-0.7-D.md。

自动推进了0.8的第一步：二维MOL V2000到未绑定JSONC导入，保留支持的化学元数据，拒绝无法表达的输入，记录源SHA-256，修复带电／同位素碳显示。后续继续身份核验与代表样本重绘，不据此宣称数据库覆盖已完成。
