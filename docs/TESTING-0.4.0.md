# 0.4.0-test.1 手动测试说明

运行目标：GTNH 2.9.0、Java 25。替换旧 moldraw JAR，确保 mods 中只有一个版本。
安装文件为 build/libs/moldraw-0.4.0-test.1.jar；不要安装 dev、sources 或 preshadow 文件。

## 本次完成

- 原版 derive 与数组/字符串式合金配方读取；统一材料名称规则。
- 通过 Minecraft 资源管理器读取现有资源，F3+T 时清空模型、配色和布局缓存。
- 修复游戏内配置保存覆盖及颜色缓存失效。
- 修复公式回退的质量二次加权；独立严格计数解析器区分 Co/CO、支持下标与嵌套括号，拒绝非法/溢出输入。
- 去掉只凭分子式选择异构体的旧回退。按名称匹配的模型仍可用。
- 恢复54份原版苯环组件资源，修复4处无效括号原子引用，恢复苯环配置切换。
- 元素入口允许读取已有氢、氧等分子模型。
- 共享模型正/负缓存，清理图形代理缓存，减少反复创建；按本模组行身份去重。
- 增加原生 en_US/zh_CN .lang，补齐 Other/Unknown。
- 版本使用构建生成值；NEI 对齐2.8.171-GTNH；CI 使用Java25。
- /moldraw audit 导出当前 GT Materials 注册表至实例 moldraw-audit/materials.csv（UTF-8 BOM，可用Excel打开）。

## 推荐测试

1. 水、乙醇、苯、聚乙烯、PBI、硅烷、氢/氧单元：Shift前后、配方页、NEI列表。
2. 钢、青铜、铌钛、不锈钢、红色合金：直接/递归、数量/质量、微量折叠。
3. 配置中改半径、颜色、苯环模式；保存后立刻观察，并重启确认持久化。
4. 开启/关闭资源包并F3+T；切换中英文、GUI缩放，观察文字和边界。
5. 连续切换悬停材料，检查是否重复图示、闪烁、残留数字、界面变色。
6. 执行 /moldraw audit。导出的 display 表示数据可用性，不代表每种物品形态均经过实测。
