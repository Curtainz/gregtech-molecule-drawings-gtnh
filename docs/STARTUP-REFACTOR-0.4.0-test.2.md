# 启动故障与分阶段重构（2026-11-03）

## 结论和证据边界

用户确认：安装 test.1 启动崩溃，禁用该 mod 后正常启动。应把 MolDraw 作为触发因素继续排查，不能因为 Windows 故障模块为 SDL3.dll 就排除 mod。

崩溃记录：2026-11-03 12:12，Windows Application Error 指向 SDL3.dll，偏移 0x15d921；Java 日志停在早期加载画面，没有 MolDraw 初始化成功记录，也没有足以定位到某行 Java 代码的异常栈。11 月 2 日也曾出现同位置的 native 故障。禁用后的日志已推进至完整加载。

这不能证明“分子渲染调用触发 SDL 崩溃”，也不能证明 FastUtil 导致故障。打包体积、加载耗时及与加载画面的交互仍是待验证因素。应继续通过真实客户端对照验证，不能把编译成功等同于修复成功。

## 本版已经实施

- CommonLifecycle / ClientLifecycle 隔离公共入口和客户端注册；公共 MolDraw 入口不再直接操作 Minecraft、NEI 或资源管理器。
- postInit 仅订阅客户端 tick；在首次客户端 tick 安装命令、资源监听与 tooltip 集成。
- 客户端线程未建立前不再默认放行；NEI tooltip 路径也应用线程检查。
- 资源重载回调只设置原子更新标记，缓存失效集中在客户端 tick。注册监听器时的立即回调不再直接初始化整组缓存。
- 添加 `[lifecycle]` 阶段日志：preInit、postInit、首次 tick、集成完成、缓存失效。
- 用 JDK 集合替换三处 FastUtil 使用，移除整个 FastUtil 打包依赖。JAR 从 27,605,749 字节降到 3,256,029 字节；class 从 13,978 减少到 1,185。此改动降低打包负担，不代表已经证实该依赖是根因。
- 689 个资源文件与 test.1 逐项 SHA-256 比对一致。结构式、饼图、Shift 提示、资源包覆盖、配置和 audit 功能代码继续保留；实际游戏行为仍需验证。

## 手动测试

1. 退出游戏，保持旧 MolDraw 禁用，仅安装 `moldraw-0.4.0-test.2.jar`；不要同时启用两个 MolDraw。其余 mod、资源包、Java 参数保持不变。
2. 先确认进入主菜单，并重复冷启动以排查偶发问题。
3. 若仍崩溃，保留本次 `fml-client-latest.log` 和启动器退出信息。重点检查 `[lifecycle]` 最后一个阶段；若连 preInit 都未到达，应优先研究 mod 扫描/打包/加载画面交互，而非继续修改绘图算法。
4. 启动成功后在原本可显示的材料上检查结构式、饼图、Shift、NEI，以及 F3+T 后显示和配置界面保存；运行 `/moldraw audit`。

## 后续重构范围与验收顺序

建议系统性重构集成架构，并逐步替换；保留可验证的资源数据和解析算法，不进行一次性全部重写。

1. **稳定启动基线（当前阶段）**：实机连续启动、退出重进、资源重载和已知材料显示通过。若仍在 preInit 前 native 崩溃，进一步制作只含元数据的最小对照包，定位打包存在性和加载时序的影响。
2. **NEI 和渲染适配层**：核实固定 NEI/CodeChicken 版本的公开接口，移除对内部 handler 列表的直接修改与动态代理；让布局计算不调用 GL，绘制只在客户端渲染回调发生，并对所有 GL 状态成对恢复。验收含普通库存、NEI 配方、ChromaticTooltips 和资源重载。
3. **材料与展示数据层**：明确稳定材料 ID、来源适配器、不可变展示模型和统一缓存版本；补齐组合权重与未知元素语义。用已知正确的材料做数据回归，避免仅以“没有异常”为通过标准。
4. **外部脚本与热重载**：先定义独立注册 API（材料 ID → 化学式、结构资源、组成），再连接脚本前端；如采用 ZenScript，应通过对应 MineTweaker/CraftTweaker 版本的真实接口集成，不把 JSON 配置冒充脚本。解析和校验生成候选快照，通过后在客户端线程原子替换；失败保留上一个有效版本并报告文件和行号；重载清理旧绑定和相关缓存，不执行任意 GL 操作。
5. **覆盖率与工具**：扩大 GTNH 材料来源适配、导出覆盖率与歧义原因；之后再推进结构推断和审核流程。

`ChemicalFormulaRegression` 中的化学式是测试输入，不是运行时白名单，也不会被打入发布 JAR。外部脚本/热重载是另一个尚未完成的功能，上述 test.2 没有宣称实现它。
