# 0.5.0-test.1：架构与组成正确性里程碑

基于已由用户实测通过的 develop/3706995；目标环境仍为 Minecraft 1.7.10、GTNH 2.9.0、Java 25。仅交付测试版，不修改 main、既有标签或 Release。下一阶段须在本阶段验收后进行。

## 已实现

- PresentationData / MaterialDefinition 表达不可变展示数据；MoleculeScene 是不持有 GT 材料或可变 JOML 向量的几何快照。
- MoleculeLayoutBuilder 与 PieLayout 完成纯布局，TextMeasure 提供文字宽度和行高；TooltipLayout 包含不可变像素、矩形和文字命令及实际边界。客户端 renderer 只提交命令，尺寸读取与绘制使用同一结果。现有键型、凯库勒式、聚合物括号与标签遮罩算法保留，负坐标及超出原启发式边框的标签会被纳入真实边界。
- MaterialRegistry 将 GT 注册数据及资源适配器汇合为单一入口。GT ID 为 `gt:<mName>`，命名流体及提示框回退使用单独的 `fluid:` / `name:` ID；翻译名不参与缓存身份。
- ABSENT / PRESENT / DISABLED / INVALID 区分资源缺失、正常、禁用和解析失败。已有资源 JSON 保持可读，增加 `{ "disabled": true }` 表达明确禁用。高优先级资源解析失败或禁用后，不偷偷使用其他同名候选掩盖问题；namespace 查找顺序保持原版兼容顺序。
- 移除未使用的分子式反查表、旧组成 long 递归算法、未知元素合并占位算法和无效的备用质量表。不按同分子式推断结构。原有元素符号与 GT 元素映射仍是基础数据，不是化学式白名单。
- 组成由 CompositionResolver 计算。GT/旧资源比例为 MIXTURE_PARTS，化学式为 STOICHIOMETRIC；每节点的相对数值先按当前数量/质量模式归一化，再分配父节点份额。BigInteger 与约分 Fraction 保留精度，标签才舍入。
- MassResolver 从已知 GT 元素质量、组成及密度计算精确质量。检查固定 GT 版本的实际 getMass 实现后，保留已知 GT 组成的 `density / 3628800 × 加权平均质量` 语义，但不沿用 long 中间运算、整数截断或无组成时的默认 Tc 元素质量。无 GT 组成但有完整可识别化学式时，按化学计量求质量；数据不足即缺失，不使用 100 或其他虚构值。布局阶段不再调用 Materials.getMass。
- 未知符号保留各自的 `symbol:<原符号>` ID。循环、深度限制和不可解析组成保留为终止节点并导出原因；缺少任何必要质量则停止整个材料的质量饼图，不显示部分份额。
- “其他”计入显示项数；上限 1 时全部归入一项。阈值使用配置十进制的精确分数，不提前舍入。所有有效原始份额之和为 1。
- 数据、组成和布局分别采用有上限的缓存。布局键包含稳定 ID、数据版本、字体对象/行高/Unicode/双向文字/语言及布局配置；资源、语言和配置变更通过现有客户端 tick 更新版本。布局上限256项、材料4096项、组成1024项、质量4096项、资源解析4096项。
- 图计算深度32、访问预算10000；JSON 2 MiB/64层；几何16384项；布局262144个栅格像素。苯环资源的环大小在分配数组前限制为3..64，画法不变。超限进入诊断路径，不进入绘制提交。
- audit 使用同一注册入口、组成结果和实际展示选择，保留原 CSV 前7列，追加结构/组成状态、来源、数量与质量精确份额、错误原因。来源为解析后的 namespace/资源地址，1.7.10公开资源接口不提供资源包名称。

## 手动验收

1. 退出游戏，禁用上一个 GTMolDraw，仅安装 `gtmoldraw-0.5.0-test.1.jar`。继续使用现有 gtmoldraw.cfg；没有 modid 或配置路径迁移。
2. 多次冷启动；检查主菜单、普通库存、NEI 配方和流体、ChromaticTooltips，以及 Shift 切换。检查水、苯、已有聚合物的图形、标签和括号。
3. 检查青铜、黄铜和嵌套合金饼图：分别切换 partsByMass / recursive；数量模式应按相对份数分配，质量模式按已知质量分配，子材料展开后不增加其父份额。
4. 设置 maxComponentsDisplayed=1，确认只显示100%的“其他”；恢复为2、8，确认“其他”占用一项。测试 minPercentageThreshold=0 和100。
5. 修改颜色和比例配置、切换中英文、F3+T，确认图形尺寸、标签和颜色不残留旧缓存；退出世界再进入。
6. `/gtmoldraw audit` 输出 `.minecraft/gtmoldraw-audit/materials.csv`。有效数量/质量份额分别求和应为1；失败质量结果为空，诊断含 MISSING_MASS 等原因。曾依赖虚构质量的材料可能不再显示质量饼图，可切换数量模式查看；这是有意修正。
7. 用临时资源包覆盖一个已有组成资源为 `{ "disabled": true }`，F3+T后该材料饼图应禁用；再改为无效组成，应有INVALID诊断并安全回退。移除覆盖后F3+T应恢复。临时资源包不随本版发布。
8. 若异常，保留本次 fml-client-latest.log 和 audit CSV。此前 native DLL 故障仍保留为回归场景；本版不能证明已定位该故障的具体根因。
