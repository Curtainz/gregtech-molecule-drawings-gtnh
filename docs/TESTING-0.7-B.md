# 0.7.0-test.B 测试说明

安装ZIP只包含 mods 和 config，不再包含文档／图册。删除旧JAR，覆盖官方包并安装 gtnh_species 包，保留自定义包。建议备份0.7-A以便回退；本包不修改游戏注册表。

## 验收

1. 中文环境进入世界，检查 status 为两包；对 Draconium、觉醒龙、Naquadria、InfusedGold 等执行 audit。Draconium 不得再分解成氘，终止物种不得产生自循环。没有来源的质量仍禁用，切换数量模式检查组成。
2. 检查二甲苯、聚苯并咪唑公式中的专用下标零得到规范化。问号仍保持未知。
3. 重新 audit，确认材料名称不再为空。上一版空格式参数导致GT材料名称为空，本版使用 %material。
4. preview 发布包已使用本次实机 audit 加入中文名称。对于旧快照材料空名，按 providerId 关联已有中文流体名；这些关联是名称对照，不更改化学绑定。没有名称来源仍明确标记。
5. ZIP内JAR时间保留构建文件修改时间，JAR内部条目继续使用可重现构建时间。
6. 回归冷启动、NEI、Shift、F3+T、配置变更、重复进出世界及失败热重载。

独立 preview 仍支持 --audit snapshot.json。构建时可用 -PauditSnapshot=<绝对路径> 将名称快照加入图册，CI不依赖本机游戏目录。

## 数据接口

v1材料定义新增 terminal 布尔字段，表示不可再按显示公式分解的物种，禁止同时提供composition。element_binding目标可引用包内材料，必须存在；旧GT引用仍兼容。新包最低版本0.7.0-test.B；旧加载器无法读取新字段时应保留旧快照。

Ma*注册为独立终止物种，没有游戏质量来源，不继承Ma质量。Nq+与Nq⁺作为显式游戏状态符号注册，普通离子电荷不进行通用推断。Dr*未作为无证据的龙元素别名自动加入。GT字形只转换已核验的下标零，已注册特殊符号按最长匹配读取。

本轮实现0.7-B第一批物种；真实元素的非GT身份桥接、其它魔法字形注册与完整schema2迁移仍需后续分批推进。0.7-C的直接流体GUI验收尚未完成。
