# 第②阶段样例数据

这是JSONC格式v1的小型样例，不是完整官方材料包。0.6.0-stage.2游戏尚未启用本格式。

- packs/official：水、苯、苯酚、稠环、聚合物和组成样例。
- packs/user：必须显式声明覆盖与依赖的示例。
- schema/：供编辑器使用的JSON Schema；跨引用和组装语义由离线工具验证。
- FORMAT-V1.md：字段、模块、坐标、共享及覆盖的规范。

需要直接看图时，使用同版本的 `gtmoldraw-stage-2-preview.zip`，解压后打开 `preview/index.html`。

工具与游戏JAR测试步骤见仓库 `docs/STAGE-2-TESTING.md`。不要将工具JAR放进mods，也不要用这些样例替换现有游戏资源。
